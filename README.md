# К1986ВК01GI · воспроизведение WAV через ЦАП

Подключим наушники к отладочной плате К1986ВК01GI и запустим пример `dac_music`. В статье для проверки взято пение птиц. Аудиоотсчёты из WAV заранее перенесены в массив `arraymusic[]`, а прошивка по кругу подаёт их в два встроенных ЦАП. На плате оба канала заведены на усилитель **TPA6130A2**.

```mermaid
flowchart LR
    A["arraymusic[]"] --> B["FIFO DAC1 и DAC2"]
    B --> C["TPA6130A2"]
    C --> D["Разъём 3,5 мм"]
```

## Собираем пример

1. Установите **Keil µVision** с **Arm Compiler 5.06**. В исходном проекте указаны Arm Compiler 5.06 update 6, пакет `Keil.MDR1986VK01.1.3` и компонент CMSIS Core 5.5.0 из пакета ARM.CMSIS 5.8.0. [Пакеты Миландр (Milandr)][software].
2. Скачайте [оригинальный архив `dac_music_support.zip`][archive] и восстановите файлы, на которые ссылается проект.

   ```console
   python tools/import_support.py dac_music_support.zip
   ```

   Скрипт добавит `arraymusic.h`, `RTE/Device/` и `RTE/Board_Support/`.

3. Откройте [dac_music.uvprojx](dac_music.uvprojx), выберите цель **FLASH** и соберите проект. Если Keil сообщает об ограничении размера образа, оставьте в `arraymusic[]` короткий фрагмент отсчётов. Такой вариант предусмотрен в статье.
4. Загрузите прошивку на плату и проверьте вывод через разъём 3,5 мм. В исходнике громкость усилителя задаёт `Volume[0]`. Для первой проверки можно уменьшить её перед сборкой.

## Как данные доходят до наушников

В [main.c](main.c) усилитель настраивается по I²C на частоте **400 кГц**. Семибитный адрес TPA6130A2 равен `0x60`. Затем программа воспроизводит один и тот же массив в обоих каналах. Для каждого канала она проверяет состояние FIFO и, когда есть место, записывает следующий отсчёт. Дойдя до конца массива, начинает сначала.

| Что | Настройка в примере |
| --- | --- |
| Исходный сигнал | PCM, один канал, 8 бит без знака, 22 050 Гц |
| Выходы ЦАП | DAC1 на PB26, DAC2 на PB23 |
| Усилитель | TPA6130A2 на отладочной плате |

Чтобы подставить другой звук, подготовьте WAV с теми же параметрами и перенесите в `arraymusic[]` отсчёты из секции `data`. В статье показано, как найти эту секцию в HEX-редакторе. [Разбор WAV и настройка усилителя][article].
